## C. 张力

### Problem Description

胖胖龙正在研究一种数字排列艺术。

他认为，对于任意两个非负整数 $x,y$，将它们相邻放置时会产生大小为 ${lowbit}(x \oplus y)$ 的"张力"。

现在，胖胖龙有一个长度为 $n$ 的非负整数序列 $a_{1},a_{2},\ldots,a_{n}$。他希望将这些数重新排列成 $b_{1},b_{2},\ldots,b_{n}$，使得相邻数字之间的总张力最小，即最小化：

$$\sum\limits_{i = 1}^{n - 1}{lowbit}(b_{i} \oplus b_{i + 1})$$

其中 $\oplus$ 表示按位异或。

对于正整数 $x$，${lowbit}(x)$ 表示 $x$ 二进制表示下最低位的 $1$ 对应的数值，例如 ${lowbit}(12) = 4$。特别地，我们定义 ${lowbit}(0) = 0$。

请你帮帮胖胖龙，求出最小可能的总张力。

### Input

每个测试点中包含多组测试数据。输入的第一行包含一个正整数$T$ ($1 \leq T \leq 100$)，表示数据组数。对于每组测试数据：

第一行一个正整数$n$ ($1 \leq n \leq 5 \times 10^{3}$)，表示序列的长度。

第二行 $n$ 个整数$a_{1},a_{2},\ldots,a_{n}$ ($0 \leq a_{i} < 2^{50}$)，表示序列 $a$。

保证所有测试数据中 $n$ 之和不超过 $2 \times 10^{4}$。

### Output

对于每组测试数据：输出一行一个整数，表示最小可能的总张力。

### Sample Input

```plain
3
3
0 1 2
5
3 4 5 6 7
8
1 8 2 0 12 1 4 2
```

### Sample Output

```plain
2
4
8
```
