## L. 飞翔的甲鱼

### Problem Description

Minato和Hinata在逛街的时候发现了许多甲鱼，不知道为什么，这些甲鱼居然会飞。
这些甲鱼在一个$1$乘$10^{10000}$的网格图上,格子从$1$开始编号，对于一只甲鱼，假设它在第$x$个格子，它可以飞到任意$y < x$且第$y$个格子上没有甲鱼的格子上。
Hinata想用这些甲鱼和Minato玩游戏，他们两人轮流操作，每次选择一只甲鱼将它飞到另一个格子，不能操作的人输。Hinata希望知道在她先手的情况下是否有必胜策略，你能帮帮她吗？
因为甲鱼有很多，所以你要对$T$组数据分别给出答案。

### Input

第一行一个整数$T \leq 10000000$，表示数据组数。
接下来每组数据第一行一个整数$n$，表示该组数据的甲鱼个数，保证 $1 \leq n \leq 100000,\sum n \leq 200000000$。
接下来一行$n$个整数$a_{1}\ldots a_{n}(1 \leq a_{i} \leq 2^{31} - 1)$，以空格分隔，表示每只甲鱼的位置，保证甲鱼的位置互不相同。保证 $a_{i}$ 递增给出。

### Output

$T$行，每行一个字符串。
如果$Hinata$有必胜策略，输出\"YES\"。
否则输出\"NO\"。

### Sample Input

```plain
2
2
1 4
4 
2 3 5 8
```

### Sample Output

```plain
YES
NO
```
