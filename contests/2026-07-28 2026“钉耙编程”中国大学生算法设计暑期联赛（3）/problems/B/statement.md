## B. The World Cup

### Problem Description

2034
年，由于中国队进了沙特世界杯，为这届世界杯带来了巨大的经济收益，主办方喜笑颜开，决定举办一场不收税的全球赌球大赛

这届世界杯一共有$n$ 支球队，在这场全球赌球大赛中，每支球队有夺冠赔率 $x_{i}$，代表着如果花 1
元钱赌这支球队最终夺冠，如果这支球队最终真的夺冠的话，将会回报 $x_{i}$ 元。同样的，可以赌第 $i$ 支球队不会夺冠，此时赔率是 $\frac{x_{i}}{x_{i} - 1}$（为了保证游戏的公平性）。

小 H 在这场赌球大赛中嗅到了商机，他准备花费 $w$ 块钱参与这个赌球大赛。小 H
非常厌恶风险，因此他想知道有没有一种投资策略，在$w$ 块钱全部赌出去的情况下，使得最后得到的回报最坏情况下最大。

### Input

第一行一个正整数 $T$ （ $T \leq 10^{4}$ ），表示数据组数。

对于每组数据，第一行会有两个整数 $n,w\text{（}2 \leq n \leq 66,1 \leq w \leq 10^{9}\text{）}$，表示这决世界杯参赛球队，以及小
H 准备投入的钱。

第二行会有 $n$ 个整数，第 $i$ 个整数为 $x_{i}\text{（}2 \leq x_{i} \leq 200\text{）}$，表示第 $i$ 支球队获胜的赔率。

### Output

每行一个数字，表示第$i$ 组数据对应的答案，与标准答案绝对误差在 $10^{- 4}$ 内视为正确。

### Sample Input

```plain
2
2 20
2 3
3 20
3 3 3
```

### Sample Output

```plain
24.0000000000
20.0000000000
```
