## F. Special Judge

### Problem Description

给定整数 $n$，从$\lbrack 1,n\rbrack$ 中选出一个最大集合，使这个集合两两互不整除。如果有多种解，给出字典序最小的那个。

### Input

第一行一个整数 $T\text{（}1 \leq T \leq 10\text{）}$，表示数据组数。

对于每组数据，每行一个整数 $n\text{（}1 \leq n \leq 1500\text{）}$。

### Output

对于每组数据，第一行输出一个整数 $k$，表示所选集合大小。

第二行输出$k$ 个互不相同的整数，表示所选集合中的元素。

### Sample Input

```plain
1
3
```

### Sample Output

```plain
2
2 3
```
