## H. 水豚噜噜的平衡树

### Problem Description

可爱的水豚噜噜走在树下，可是雨滴从树上掉到它的大大的脸上。噜噜有一个想法，有没有可能雨滴在树上是平衡的，就不会砸到它？由于你也很喜欢可爱的噜噜，所以你要帮它解决这道题。
- -----------------------------------------------------------------------

给定一棵有 $n$ 个点的树。第 $i$ 个点初始有 $a_{i}$ 单位水滴，并且最终至多能够容纳 $b_{i}$ 单位水滴。

同时给出一个长度为 $n$ 的排列 $p$，其中$p_{i}$ 表示点 $i$ 的镜像点。输入保证树和映射 $p$ 满足：

1.  $p_{p_{i}} = i$；
2.  对任意树边 $u - v$，$p_{u} - p_{v}$     也是树边；
3.  对称中心恰好为以下两种情况之一：
- 存在唯一的点 $c$ 满足 $p_{c} = c$；
- 不存在固定点，并且存在唯一的边 $x - y$ 满足 $p_{x} = y,p_{y} = x$。

每条边 $u - v$ 有一个运输系数 $w$。

一次操作可以选择一条边 $u - v$ 和一个正整数 $x$，把$x$ 单位水滴从一个端点移动到另一个端点。操作过程中任意点的水滴数都不能为负，本次操作的代价为

$$xw.$$

你需要进行若干次操作，使最终水滴数$c_{i}$ 满足：

$$0 \leq c_{i} \leq b_{i},$$

并且对所有点 $i$ 都有

$$c_{i} = c_{p_{i}}.$$

求最小总代价。若不存在合法方案，输出 $- 1$。

注意：初始与过程中水滴数 $a_{i}$ 可以大于容量 $b_{i}$，容量限制只针对最终状态。

### Input

第一行一个整数 $T$，表示测试数据组数。

对于每组数据：
- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $a_{1},a_{2},\ldots,a_{n}$；
- 第三行 $n$ 个整数 $b_{1},b_{2},\ldots,b_{n}$；
- 第四行 $n$ 个整数 $p_{1},p_{2},\ldots,p_{n}$；
- 接下来 $n - 1$ 行，每行三个整数 $u,v,w$，表示树边 $u - v$ 的运输系数为 $w$。

$$1 \leq T \leq 30,$$

$$1 \leq \sum n \leq 2 \times 10^{5},$$

$$0 \leq a_{i},b_{i} \leq 600,$$

$$1 \leq w \leq 10^{9},$$

并且对每组数据均保证

$$\sum\limits_{i = 1}^{n}a_{i} \leq 600.$$

输入保证树与镜像映射$p$ 满足题目描述中的全部性质。

### Output

对于每组数据输出一行一个整数，表示最小总代价；若无解，输出 $- 1$。
