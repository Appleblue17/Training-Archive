## B. 会自动求和的序列

### Problem Description

有两个长度为 $n$ 的序列 $a$ 和 $b$。

接下来依次经过 $m$ 天。每天开始时，对于所有 $1 \leq i \leq n$，先执行 $\left. a_{i}\leftarrow a_{i} + b_{i} \right.$，然后执行当天的一次操作。

操作共有以下两种：

`1 l r x`：对于所有 $l \leq i \leq r$，执行 $\left. b_{i}\leftarrow b_{i} + x \right.$。

`2 l r`：求当前区间和$\sum_{i = l}^{r}a_{i}$ 对 $2^{64}$ 取模后的结果。

### Input

第一行包含一个整数 $T$，表示测试用例的组数。

对于每组测试用例，第一行包含两个整数 $n,m$，分别表示序列长度和天数。

接下来 $n$ 行，第 $i$ 行包含两个整数 $a_{i},b_{i}$，表示两个序列的初始值。

接下来 $m$ 行，每行包含一次操作，格式为
`1 l r x` 或 `2 l r`。

对于 OJ 中唯一一组正式测试数据，保证： $T = 10^{4}$； $2 \leq n \leq 5 \times 10^{5}$； $1 \leq m \leq 5 \times 10^{5}$； $1 \leq a_{i},b_{i} \leq 10^{9}$； $1 \leq l < r \leq n$； $1 \leq x \leq 10^{9}$； $\sum n = 10^{6}$； $\sum m = 10^{6}$。

### Output

对于每次第二类操作，输出一行一个整数，表示询问结果对 $2^{64}$ 取模后的值。

结果应表示为 $0$ 到 $2^{64} - 1$ 之间的十进制整数。

### Sample Input

```plain
1
4 4
1 2
2 1
1 1
2 2
2 1 4
1 1 2 1
2 1 3
2 2 4
```

### Sample Output

```plain
12
18
23
```
