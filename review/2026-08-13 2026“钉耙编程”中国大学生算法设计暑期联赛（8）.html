题目分析：

给定一个二分图（保证存在黑白染色方案），求 k 元环的数量，其中 k 是质数。由于图是二分图，所有环的长度必须为偶数。当 k 为大于 2 的质数时，k 必为奇数，因此不存在 k 元环，答案为 0。当 k = 2 时，只需要统计重边的数量即可。

代码分析：

// 第二次提交改为排序后统计，仍然 TLE

A. 让路径生存吧！（简单题）

  • 知识点：图论、二分答案、BFS/DFS
  • 难度：★★
  • 首次提交：12:21（WA）
  • AC 时间：12:29
  • 错误次数：3（WA × 3）

题目分析：

给定一个有向图，依次删除从某些点出发的所有边，求最大的操作次数 k 使得执行完前 k 次操作后仍存在从 1 到 n 的路径。

解题思路：

由于操作是永久删除从点 p i p_i pi​ 出发的所有边，且 p i p_i pi​ 两两不同，可以将问题转化为二分答案。对于给定的 k，只保留未被删除的点（即 p k + 1 , … , p q p_{k+1}, \ldots, p_q pk+1​,…,pq​ 对应的点）的出边，然后 BFS 判断 1 是否能到达 n。

代码分析：

bool check(int lim){
    for(int i=1; i<=n; ++i) g[i].clear(), vis[i]=0;
    for(int i=lim+1; i<=n; ++i){
        g[a[i]]=e[a[i]];
    }
    // BFS 判断 1 是否能到达 n
}

错误原因分析：

三次 WA 的原因分别如下：

  1. 第一次 WA：二分边界设置错误。int l=0, r=n，当 ret==0 时输出 NO，但初始时可能存在路径，此时 ret 应该至少为 0。问题在于当 ret==0 时，可能初始就不存在路径（应该输出 NO），也可能前 0 次操作后存在路径但第 1 次操作后不存在（应该输出 0）。代码中 if(ret==0) printf("NO\n") 将两种情况混为一谈。

  2. 第二次 WA：二分边界改为 r=n+1，但 ret>k 的判断条件仍然有问题。当 ret==k 时，说明执行完全部 k 次操作后仍然存在路径，应该输出 YES，但代码中 ret>k 的条件无法覆盖 ret==k 的情况。

  3. 第三次 WA：增加了 if(!check(0)) 的特判来处理初始不存在路径的情况，但二分边界仍然使用 r=n+1，且 ret>k 的判断仍然有问题。

  4. 最终 AC：将 r 改回 n，并将 ret>k 改为 ret>=k，同时保留 if(!check(0)) 的特判。

关键转折点：

这道题的教训在于二分边界的处理。ret==k 时应该输出 YES 而不是 ret，因为 ret 最大只能到 k（操作次数只有 k 次）。队伍在第三次 WA 后意识到了这个问题，将 ret>k 改为 ret>=k 后成功 AC。

解题思路：

int m=P.size()/2;

代码中 V 存储的是已经确定位置的数（即非零且与另一个位置配对后确定的数），P 存储的是所有未出现的数。通过分类讨论计算出方案数。

B. 会自动求和的序列（中等题）

  • 知识点：线段树、懒标记、自然溢出
  • 难度：★★★
  • 首次提交：13:03（AC）
  • AC 时间：13:03
  • 错误次数：2（CE × 2，误交至 L 题）

题目分析：

有两个长度为 n 的序列 a 和 b，每天先执行 a i ← a i + b i a_i \leftarrow a_i + b_i ai​←ai​+bi​，然后执行操作。操作有两种：区间加 b 和区间查询 a 的和（对 2 64 2^{64} 264 取模）。

解题思路：

关键在于推导出 a 的变化规律。设第 t 天开始时 a 的值为 a i ( t ) a_i^{(t)} ai(t)​，b 的值为 b i ( t ) b_i^{(t)} bi(t)​。则：

  • 第 t 天开始时： a i ( t ) = a i ( 1 ) + t ⋅ b i ( 1 ) + ∑ j = 1 t − 1 ( t − j ) ⋅ x j ⋅ [ i ∈ [ l j , r j ] ] a_i^{(t)} = a_i^{(1)} + t \cdot b_i^{(1)} + \sum_{j=1}^{t-1} (t-j) \cdot x_j \cdot [i \in [l_j, r_j]] ai(t)​=ai(1)​+t⋅bi(1)​+∑j=1t−1​(t−j)⋅xj​⋅[i∈[lj​,rj​]]

因此，可以用两棵线段树分别维护 b 的区间加和 a 的初始值加上 b 的加权和。具体来说，维护两个值：

  • sm[0]：维护 a i − t ⋅ b i a_i - t \cdot b_i ai​−t⋅bi​ 的和
  • sm[1]：维护 b i b_i bi​ 的和

查询时答案为 query(0) + t * query(1)。

代码分析：

关键转折点：

在 12:53 和 12:56 有两次 CE 提交，且都提交到了 L 题而非 B 题。从代码内容来看，这两次提交实际上是 B 题的代码，但提交时选择了错误的题目编号。这是一个典型的低级失误，可能是队员在提交时没有仔细确认题目编号。

  2. 调试输出在提交前必须删除或注释掉。

C. 太近就不合法了（中等题）

  • 知识点：组合数学、DP、分块预处理
  • 难度：★★★
  • 首次提交：13:16（AC）
  • AC 时间：13:16
  • 错误次数：0

题目分析：

有 n 个位置，每次询问给定 x 和 k，要求选择若干位置使得位置 x 不被选择，且任意两个被选择位置的编号之差的绝对值不小于 k。求方案数。

解题思路：

设 f ( n , k ) f(n, k) f(n,k) 表示在 n 个位置中选择若干位置（可以不选），任意两个被选择位置距离不小于 k 的方案数。则答案为：

f ( n , k ) − f ( x − k , k ) × f ( n − x − k + 1 , k ) f(n, k) - f(x-k, k) \times f(n-x-k+1, k) f(n,k)−f(x−k,k)×f(n−x−k+1,k)

其中 f ( x − k , k ) f(x-k, k) f(x−k,k) 表示在 x 左侧（距离 x 至少 k）的选择方案数， f ( n − x − k + 1 , k ) f(n-x-k+1, k) f(n−x−k+1,k) 表示在 x 右侧的选择方案数。

对于 f ( n , k ) f(n, k) f(n,k) 的计算，可以使用 DP： f ( i ) = f ( i − 1 ) + f ( i − k ) + 1 f(i) = f(i-1) + f(i-k) + 1 f(i)=f(i−1)+f(i−k)+1（不选第 i 个位置或选第 i 个位置）。

代码分析：

int B;
int pre[M][N];
int f[N],s[N];

int cal(int n,int k){
    if(n<=0) return 1;
    if(k<=B) return pre[k][n];
    else{
        int tot=1;
        for(int t=1;(k-1)*(t-1)<=n-t && t<=n;t++) gmod(tot+=C(n-(k-1)*(t-1),t));
        return tot;
    }
}

使用分块思想：对于 k ≤ B k \leq B k≤B 的情况，预处理所有答案；对于 k > B k > B k>B 的情况，直接使用组合数公式计算。

评价：

一次通过，说明队伍的 DP 和分块预处理能力较强。代码结构清晰，预处理和查询逻辑正确。

G. 用传送门来让网格连通吧（中等偏难）

  • 知识点：图论、强连通分量（SCC）、传递闭包、IO 优化
  • 难度：★★★★
  • 首次提交：13:33（TLE）
  • AC 时间：14:08
  • 错误次数：4（TLE × 4）

题目分析：

给定一个 n × m n \times m n×m 的网格，有障碍物和传送门。每次询问从起点能否到达终点。

解题思路：

将网格中的可通行格子作为节点，相邻可通行格子之间连无向边，传送门作为有向边。然后求强连通分量（SCC），缩点后得到 DAG。对于每个 SCC，DFS 求出它能到达的所有 SCC，存储在一个哈希表中。查询时只需要判断两个点所在的 SCC 是否相同或可达。

代码分析：

void dfs(int x, int rt){
    if(h[rt].find(x)!=h[rt].end()) return ;
    h[rt][x]=1;
    for(auto y:g[x]) dfs(y, rt);
}

对每个 SCC 进行 DFS，将可达的 SCC 存入 unordered_map<int, bool> h[rt] 中。

错误原因分析：

四次 TLE 的原因如下：

  1. 第一次 TLE：使用 vector<char> a[N] 存储网格，且使用 unordered_map<int, bool> h[N]，没有使用快读。vector<char> 的访问效率较低，且 unordered_map 的常数较大。

  2. 第二次 TLE：改为使用一维数组 char s[N] 存储网格，但输入仍然使用 scanf，且 unordered_map 仍然存在。

  3. 第三次 TLE：改为使用 getchar() 逐字符读入，但仍然使用 unordered_map。

  4. 第四次 TLE：增加了 if(g[i].empty()) continue; 的优化，但仍然使用 unordered_map。

  5. 最终 AC：加入自定义快读 struct IO，使用 fread 和 fwrite 实现高效的输入输出。

关键转折点：

这道题的核心问题在于 IO 效率。unordered_map 虽然常数较大，但在 s c c c n t ≤ 5 × 10 4 scccnt \leq 5 \times 10^4 scccnt≤5×104 的情况下应该可以接受。真正的瓶颈在于输入输出。 q q q 最大为 10 5 10^5 105， T T T 最大为 400， ∑ q = 10 7 \sum q = 10^7 ∑q=107，使用 scanf 和 printf 在如此大的数据量下确实会超时。

最终 AC 的提交使用了自定义快读，运行时间从 TLE 降到了 937 MS，效果显著。

教训：

对于 ∑ q ≥ 10 7 \sum q \geq 10^7 ∑q≥107 的题目，必须使用自定义快读。scanf/printf 在如此大的数据量下是不够的。

H. 分数越小还是越大越好（中等题）

  • 知识点：树形 DP、树的直径、MEX
  • 难度：★★★★
  • 首次提交：14:04（AC）
  • AC 时间：14:04
  • 错误次数：0

题目分析：

给定一棵树，需要给每个顶点分配一个 0 到 N-1 的排列作为标签。定义 f ( u , v ) = M E X ( { P x ∣ x ∈ V ( u , v ) } ) f(u,v) = MEX(\{P_x | x \in V(u,v)\}) f(u,v)=MEX({Px​∣x∈V(u,v)})，树的分数为所有点对 f ( u , v ) f(u,v) f(u,v) 之和。求最小和最大可能分数。

解题思路：

对于最小分数：当树为链时，答案为 2 N − 1 2N-1 2N−1；否则答案为 N + 1 N+1 N+1。这是因为 MEX 的值取决于路径上是否包含标签为 0 的点。最小化分数需要将 0 放在一个特殊位置。
