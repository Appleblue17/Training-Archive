C. 今晚吃春天

Problem Description

提示：本题中的斗地主游戏可能与实际情况不同，请参赛选手务必仔细阅读题目描述。

"四人斗地主"是普通斗地主游戏的变体。玩家一共有四人，其中一人是地主，其余三人是农民，记为一、二、三号农民。四人共持有总计 108 108 108 张扑克牌。这 108 108 108 张牌由两张"大王"、两张"小王"和 104 104 104 张点数牌组成。每张点数牌拥有一个不超过 13 13 13 的正整数，称为点数，从小到大依次用字符 3456789TJQKA2 表示，例如 3 对应的点数是 1 1 1，T 对应的点数是 8 8 8，2 对应的点数是 13 13 13。每种点数牌各有 8 8 8 张，共计 104 104 104 张。在此基础上，规定"小王"的点数为 14 14 14，"大王"的点数为 15 15 15，这两种牌分别用字符 w 和 W 表示。这样，每一张扑克牌都有对应的点数和符号了。

游戏开始时，地主拥有 33 33 33 张牌，三位农民每人拥有 25 25 25 张牌。游戏将进行若干回合，直到有人出完手中所有的牌：

  • 每回合的首发者先出牌（游戏开始时，首发者是地主）。
  • 每回合的首发者必须从自己拥有的牌中挑选若干张打出，且出的牌必须组成一种合法牌型（见下文）。出过的牌将被弃置不再使用。
  • 接下来按照顺序，玩家依次选择是否跟出牌。例如若首发者是地主，那么接下来依次询问一号农民、二号农民、三号农民、地主、一号农民、二号农民、三号农民，以此类推。注意同一人可以在同一回合中多次出牌。
  • 如果某位玩家跟出牌，那么必须从自己拥有的牌中挑选若干张打出，所出的牌必须也组成一种合法牌型，且必须比上一位出牌者出的牌更大（见下文）。出过的牌将被弃置不再使用。
  • 如果某一时刻，有连续三位玩家均选择不出牌，本回合结束，最后一位出牌的玩家成为下一回合的首发者。
  • 如果在某一回合的某一次出牌中，出牌者出完了手中所有的牌，那么游戏立即结束，该玩家所属的阵营获胜。

四人斗地主一共有十类合法牌型：

  • 单张 S ( a ) \text{S}(a) S(a)：由一张点数为 a a a 的牌组成，满足 1 ≤ a ≤ 15 1 \leq a \leq 15 1≤a≤15。
  • 对子 D ( a ) \text{D}(a) D(a)：由两张点数为 a a a 的牌组成，满足 1 ≤ a ≤ 15 1 \leq a \leq 15 1≤a≤15。
  • 三张 T ( a ) \text{T}(a) T(a)：由三张点数为 a a a 的牌组成，满足 1 ≤ a ≤ 13 1 \leq a \leq 13 1≤a≤13。
  • 三带二 C ( a , b ) \text{C}(a,b) C(a,b)：由三张点数为 a a a 和两张点数为 b b b 的牌组成，满足 a ≠ b a \neq b a=b， 1 ≤ a ≤ 13 1 \leq a \leq 13 1≤a≤13， 1 ≤ b ≤ 15 1 \leq b \leq 15 1≤b≤15。
  • 顺子 SS ( l , r ) \text{SS}(l,r) SS(l,r)：由点数为 l l l 至 r r r 中的牌组成，每种各一张，满足 5 ≤ l + 4 ≤ r ≤ 12 5 \leq l + 4 \leq r \leq 12 5≤l+4≤r≤12。
  • 连对 SD ( l , r ) \text{SD}(l,r) SD(l,r)：由点数为 l l l 至 r r r 中的牌组成，每种各两张，满足 3 ≤ l + 2 ≤ r ≤ 12 3 \leq l + 2 \leq r \leq 12 3≤l+2≤r≤12。
  • 钢板 ST ( l , r ) \text{ST}(l,r) ST(l,r)：由点数为 l l l 至 r r r 中的牌组成，每种各三张，满足 2 ≤ l + 1 ≤ r ≤ 12 2 \leq l + 1 \leq r \leq 12 2≤l+1≤r≤12。
  • 飞机 SC ( l , r , P ) \text{SC}(l,r,P) SC(l,r,P)：由点数为 l l l 至 r r r 中的牌组成，每种各三张，满足 2 ≤ l + 1 ≤ r ≤ 12 2 \leq l + 1 \leq r \leq 12 2≤l+1≤r≤12；外加 r − l + 1 r - l + 1 r−l+1 个对子 P = { D ( x 1 ) , D ( x 2 ) , ⋯   , D ( x r − l + 1 ) } P = \{\text{D}(x_{1}),\text{D}(x_{2}),\cdots,\text{D}(x_{r - l + 1})\} P={D(x1​),D(x2​),⋯,D(xr−l+1​)}。注意： x 1 , x 2 , ⋯   , x r − l + 1 x_{1},x_{2},\cdots,x_{r - l + 1} x1​,x2​,⋯,xr−l+1​ 不必互不相同，也允许为 l l l 至 r r r 中的点数。也就是说，一共有 5 ( r − l + 1 ) 5(r - l + 1) 5(r−l+1) 张牌。
  • 炸弹 B ( x , a ) \text{B}(x,a) B(x,a)：由 x x x 张点数为 a a a 的牌组成，满足 4 ≤ x ≤ 8 4 \leq x \leq 8 4≤x≤8， 1 ≤ a ≤ 13 1 \leq a \leq 13 1≤a≤13。
  • 王炸：由两张"大王"、两张"小王"组成。

可以得知，每种合法牌型恰好属于上面十种类型中的一种。

合法牌型 X X X 要想比合法牌型 Y Y Y 大，需要满足下面的条件：

  • 王炸比所有其余合法牌型都大。一整场游戏中只能有一个王炸，因此比较王炸之间的大小没有意义。
  • 炸弹比不是炸弹或王炸的合法牌型大。
  • 对于两个炸弹 X = B ( x 1 , a 1 ) X = \text{B}(x_{1},a_{1}) X=B(x1​,a1​) 和 Y = B ( x 2 , a 2 ) Y = \text{B}(x_{2},a_{2}) Y=B(x2​,a2​)， X X X 比 Y Y Y 大的充要条件为 x 1 > x 2 x_{1} > x_{2} x1​>x2​ 或者 x 1 = x 2 x_{1} = x_{2} x1​=x2​ 且 a 1 > a 2 a_{1} > a_{2} a1​>a2​。
  • 对于前八类合法牌型，不同类之间不能比较大小。也就是说，不能拿与上一个人出的牌不同类的前八类牌型来接牌。
  • 对于两个单张 X = S ( a 1 ) X = \text{S}(a_{1}) X=S(a1​) 和 Y = S ( a 2 ) Y = \text{S}(a_{2}) Y=S(a2​)、两个对子 X = D ( a 1 ) X = \text{D}(a_{1}) X=D(a1​) 和 Y = D ( a 2 ) Y = \text{D}(a_{2}) Y=D(a2​) 或两个三张 X = T ( a 1 ) X = \text{T}(a_{1}) X=T(a1​) 和 Y = T ( a 2 ) Y = \text{T}(a_{2}) Y=T(a2​)， X X X 比 Y Y Y 大的充要条件为 a 1 > a 2 a_{1} > a_{2} a1​>a2​。
  • 对于两个三带二 X = C ( a 1 , b 1 ) X = \text{C}(a_{1},b_{1}) X=C(a1​,b1​) 和 Y = C ( a 2 , b 2 ) Y = \text{C}(a_{2},b_{2}) Y=C(a2​,b2​)， X X X 比 Y Y Y 大的充要条件为 a 1 > a 2 a_{1} > a_{2} a1​>a2​。也就是说，三带二牌型比较大小只看三张的部分，不看两张的部分。三张部分一样大的三带二牌型视为相等，无论两张部分是否一样大。
  • 对于两个顺子 X = SS ( l 1 , r 1 ) X = \text{SS}(l_{1},r_{1}) X=SS(l1​,r1​) 和 Y = SS ( l 2 , r 2 ) Y = \text{SS}(l_{2},r_{2}) Y=SS(l2​,r2​)、两个连对 X = SD ( l 1 , r 1 ) X = \text{SD}(l_{1},r_{1}) X=SD(l1​,r1​) 和 Y = SD ( l 2 , r 2 ) Y = \text{SD}(l_{2},r_{2}) Y=SD(l2​,r2​) 或两个钢板 X = ST ( l 1 , r 1 ) X = \text{ST}(l_{1},r_{1}) X=ST(l1​,r1​) 和 Y = ST ( l 2 , r 2 ) Y = \text{ST}(l_{2},r_{2}) Y=ST(l2​,r2​)，若 r 1 − l 1 ≠ r 2 − l 2 r_{1} - l_{1} \neq r_{2} - l_{2} r1​−l1​=r2​−l2​，则 X X X 和 Y Y Y 不能比较大小；否则， X X X 比 Y Y Y 大的充要条件为 r 1 > r 2 r_{1} > r_{2} r1​>r2​。
  • 对于两个飞机 X = SC ( l 1 , r 1 , P 1 ) X = \text{SC}(l_{1},r_{1},P_{1}) X=SC(l1​,r1​,P1​) 和 Y = SC ( l 2 , r 2 , P 2 ) Y = \text{SC}(l_{2},r_{2},P_{2}) Y=SC(l2​,r2​,P2​)，若 r 1 − l 1 ≠ r 2 − l 2 r_{1} - l_{1} \neq r_{2} - l_{2} r1​−l1​=r2​−l2​，则 X X X 和 Y Y Y 不能比较大小；否则， X X X 比 Y Y Y 大的充要条件为 r 1 > r 2 r_{1} > r_{2} r1​>r2​。也就是说，飞机牌型比较大小只看连续三张的部分，不看剩余两张的部分。连续三张部分一样大的飞机牌型视为相等，无论剩余两张部分是否一样大。

现在 Silvefish 当上了地主，并得到了属于他的 33 33 33 张牌。真是一手好牌啊！Silvefish 想起了"春天"。"春天"是四人斗地主中的一种特殊现象，指从游戏开始到游戏结束的过程中，所有农民均未打出任何一张牌。现在他想知道，他是否有 100 % 100\% 100% 的把握打出"春天"。他不知道农民手里的牌，所以这意味着他需要有一种出牌策略，使得无论农民剩余的 75 75 75 张牌如何分成三份（每份 25 25 25 张牌）给农民，他都一定能打出"春天"。可以认为农民们都非常希望出牌，只有他们真的无法打出任何牌时，才会选择不出。可惜手里的牌太多了，他算不过来。你能告诉他答案吗？

Input

本题包含多组测试数据。

首先在第一行输入一个整数 T T T（ 1 ≤ T ≤ 5 × 10 4 1 \leq T \leq 5 \times 10^{4} 1≤T≤5×104）表示测试数据组数。

接下来对于每一组测试数据：

输入包含一行一个长度为 33 33 33 的字符串，表示 Silvefish 作为地主拿到的 33 33 33 张牌。保证字符串中的所有字符均为 Ww2AKQJT9876543 中的字符，且按照该顺序（也就是点数从大到小）依次输入，含义见题面描述。

保证每一组测试数据都是合法的地主开局手牌。

Output

对于每一组测试数据，如果 Silvefish 有 100 % 100\% 100% 的把握打出"春天"，那么输出一行一个字符串 Yes，否则输出一行一个字符串 No。

Sample Input

2
WW22222222AAKKQQTT777666555444333
W22AAKKQQQJJJTTT99988775544443333

Sample Output

Yes
No

Hint

样例包含两组测试数据。

在第一组测试数据中，Silvefish 可以选择先打出炸弹 B ( 8 , 13 ) \text{B}(8,13) B(8,13)（也即 22222222），农民无法接牌；然后再将剩余的 25 25 25 张牌作为飞机 SC ( 1 , 5 , { D ( 8 ) , D ( 10 ) , D ( 11 ) , D ( 12 ) , D ( 15 ) } ) \text{SC}(1,5,\{\text{D}(8),\text{D}(10),\text{D}(11),\text{D}(12),\text{D}(15)\}) SC(1,5,{D(8),D(10),D(11),D(12),D(15)})（也即 WWAAKKQQTT777666555444333）一次性打出，从而达成"春天"。

第二组测试数据取自真实生活中的一局四人斗地主，可以证明在这种情况下 Silvefish 无法达成"春天"。
