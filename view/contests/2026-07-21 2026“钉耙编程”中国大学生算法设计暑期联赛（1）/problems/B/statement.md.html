B. 画树

Problem Description

众所周知，Arisa 是盆栽大王。今天，Arisa 希望在画布上画出利根川的结构。

利根川是一棵有 n n n 个节点的有根二叉树，根的编号固定为 1，保证对于所有节点 i i i 和 i i i 的父结点 f i f_{i} fi​ 有 f i < i f_{i} < i fi​<i。设节点 i i i 的左儿子和右儿子分别为 L i L_{i} Li​ 和 R i R_{i} Ri​。

Arisa 需要给每个节点分配一个整数坐标 U i = ( x i , y i ) , ( ∣ x i ∣ , ∣ y i ∣ ≤ 10 8 ) U_{i} = (x_{i},y_{i}),\left( \mid x_{i}\mid,\mid y_{i}\mid \leq 10^{8} \right) Ui​=(xi​,yi​),(∣xi​∣,∣yi​∣≤108)，满足：

  • 对于任意两个节点，分配的坐标不能相同；
  • 对于所有二叉树中的边 ( u , v ) (u,v) (u,v) ( u < v ) (u < v) (u<v)，满足 y u < y v y_{u} < y_{v} yu​<yv​；
  • 对于二叉树中任意两条边 ( a , b ) , ( c , d ) (a,b),(c,d) (a,b),(c,d)，线段 U a U b U_{a}U_{b} Ua​Ub​ 和 U c U d U_{c}U_{d} Uc​Ud​ 不允许相交或重合，但允许共用端点；
  • 对于二叉树中任意节点 i i i， i i i 的左儿子（若存在）的 x x x 坐标必须不大于 i i i 的 x x x 坐标；且 i i i 的右儿子（若存在）的 x x x 坐标必须不小于 i i i 的 x x x 坐标。即 x L i ≤ x i ≤ x R i x_{L_{i}} \leq x_{i} \leq x_{R_{i}} xLi​​≤xi​≤xRi​​。

然而，画布的大小是有限的。Arisa 使用的画布大小不能超过 66666666。即：

( max ⁡ n i = 1 x i − min ⁡ n i = 1 x i ) × ( max ⁡ n i = 1 y i − min ⁡ n i = 1 y i ) ≤ 66666666 \left( \underset{i = 1}{\overset{n}{\max}}x_{i} - \underset{i = 1}{\overset{n}{\min}}x_{i} \right) \times \left( \underset{i = 1}{\overset{n}{\max}}y_{i} - \underset{i = 1}{\overset{n}{\min}}y_{i} \right) \leq 66666666 (i=1maxn​xi​−i=1minn​xi​)×(i=1maxn​yi​−i=1minn​yi​)≤66666666

你需要帮助 Arisa 找到一个坐标分配方案，使得上述所有限制都被满足。

可以证明，在题目给定的数据范围内，对于任意二叉树都一定存在至少一种满足上述所有条件的分配方案。

Input

本题单个测试点内有多组测试数据。

第一行输入一个正整数 T T T ( 1 ≤ T ≤ 50 ) (1 \leq T \leq 50) (1≤T≤50)，表示数据组数。

接下来按如下格式输入 T T T 组数据：

第一行输入一个正整数 n n n ( 1 ≤ n ≤ 10 5 ) (1 \leq n \leq 10^{5}) (1≤n≤105)，表示二叉树的节点个数。

接下来输入 n n n 行，其中第 i i i 行输入两个整数 L i L_{i} Li​ 和 R i R_{i} Ri​ ( 0 ≤ L i , R i ≤ n ) (0 \leq L_{i},R_{i} \leq n) (0≤Li​,Ri​≤n)，表示节点 i i i 的左儿子和右儿子。若节点 i i i 没有左儿子，则 L i = 0 L_{i} = 0 Li​=0；若节点 i i i 没有右儿子，则 R i = 0 R_{i} = 0 Ri​=0。

保证输入的树是一棵以 1 为根的二叉树。

Output

对于每组数据：

输出 n n n 行，其中第 i i i 行输出两个用空格分隔的整数 x i , y i x_{i},y_{i} xi​,yi​，表示分配给节点 i i i 的坐标。

你需要保证 ∣ x i ∣ , ∣ y i ∣ ≤ 10 8 \mid x_{i}\mid,\mid y_{i}\mid \leq 10^{8} ∣xi​∣,∣yi​∣≤108。

本题使用 Special Judge 进行评测。如有多种满足所有条件的坐标分配方案，你可以输出其中的任意一种。
