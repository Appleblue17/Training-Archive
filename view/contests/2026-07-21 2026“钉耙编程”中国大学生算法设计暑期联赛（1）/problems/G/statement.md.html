G. 简单几何题

Problem Description

小 D 生活在被无尽海洋覆盖的星球上。由于行星所处的恒星系统引力极其混沌，它的自转轴和公转轨道处于极度的不稳定状态。这导致太阳光直射的方向都是完全随机的。

行星的表面可以被视作三维欧几里得空间中的单位球面 S 2 = { ( x , y , z ) ∈ R 3 : x 2 + y 2 + z 2 = 1 } S^{2} = \{(x,y,z) \in \mathbb{R}^{3}:x^{2} + y^{2} + z^{2} = 1\} S2={(x,y,z)∈R3:x2+y2+z2=1}。连接球面上任意两点（不为对跖点）的大圆上的劣弧，被称为短大圆弧。

这颗星球上仅有一块古老且连续的大陆 P P P， P P P 是一个球面简单多边形。它是由 n n n 条短大圆弧首尾相连构成的闭合区域，其边界不自交。同时，这块大陆整体被严格包含在某个开半球之内。

当太阳光在星球上的直射点为 s s s 时，星球上处于白天的区域被定义为 H s = { x ∈ S 2 : s ⋅ x > 0 } H_{s} = \{ x \in S^{2}:s \cdot x > 0\} Hs​={x∈S2:s⋅x>0}。界定白天与黑夜的大圆 s ⋅ x = 0 s \cdot x = 0 s⋅x=0 称为晨昏线。

为了在变幻莫测的气候中生存，小 D 致力于建立精确的行星气象模型。小 D 的核心任务是：在给定大陆形状与任意太阳直射点 s s s 时，计算这块大陆有多少比例的面积恰好沐浴在阳光之中。即求出以下百分比：

Area ( P ∩ H s ) Area ( P ) ⋅ 100 % \frac{\textsf{Area}(P \cap H_{s})}{\textsf{Area}(P)} \cdot 100\% Area(P)Area(P∩Hs​)​⋅100%

球面面积： Area ( P ) \textsf{Area}(P) Area(P) 指区域在单位球面上的表面积。在单位球上，一个边界大圆平面之间的二面角分别为 α , β , γ \alpha,\beta,\gamma α,β,γ 的球面三角形，其球面面积等于 α + β + γ − π \alpha + \beta + \gamma - \pi α+β+γ−π，可结合上图理解。

Input

对于每组测试数据：

第一行包含两个整数 n , q n,q n,q ( 3 ≤ n ≤ 500 , 1 ≤ q ≤ 500 ) (3 \leq n \leq 500,1 \leq q \leq 500) (3≤n≤500,1≤q≤500)，分别表示大陆多边形的顶点数和查询的太阳方向数。

接下来的 n n n 行，每行包含三个整数 x , y , z x,y,z x,y,z，表示多边形的顶点。第 i i i 个顶点对应的实际球面坐标为 ( x x 2 + y 2 + z 2 , y x 2 + y 2 + z 2 , z x 2 + y 2 + z 2 ) \left( \frac{x}{\sqrt{x^{2} + y^{2} + z^{2}}},\frac{y}{\sqrt{x^{2} + y^{2} + z^{2}}},\frac{z}{\sqrt{x^{2} + y^{2} + z^{2}}} \right) (x2+y2+z2​x​,x2+y2+z2​y​,x2+y2+z2​z​)。顶点按相对于球体外侧的逆时针顺序给出。

额外保证：

  1. 所有测试数据的 ∑ n q ≤ 5 × 10 6 \sum nq \leq 5 \times 10^{6} ∑nq≤5×106。
  2. 输入的所有坐标均满足 − 10 5 ≤ x , y , z ≤ 10 5 - 10^{5} \leq x,y,z \leq 10^{5} −105≤x,y,z≤105 且 ( x , y , z ) ≠ ( 0 , 0 , 0 ) (x,y,z) \neq (0,0,0) (x,y,z)=(0,0,0)。
  3. 令 γ = 10 − 6   rad \gamma = 10^{- 6}\ \textsf{rad} γ=10−6 rad。对于多边形任意两个不同顶点 u , v u,v u,v，它们之间的球面距离 d ( u , v ) d(u,v) d(u,v) 满足 γ ≤ d ( u , v ) ≤ π − γ \gamma \leq d(u,v) \leq \pi - \gamma γ≤d(u,v)≤π−γ。

  5. 对于任意给定的直射点 s s s 和任意顶点 p i p_{i} pi​，保证点积 s ⋅ p i ≠ 0 s \cdot p_{i} \neq 0 s⋅pi​=0，即晨昏线不会穿过任何一个多边形顶点。
