C. 边界主义

Problem Description

Rimi 正在制作 PopiV。为此，她开始研究一种叫作边界主义的电子抽象画派。

在边界主义中，画家不会直接描绘具体物体，而是从画布的左右边缘拖出色块，让它们在画布上互相覆盖。Rimi 准备在一张大小为 n × n n \times n n×n 的电子画布上作画。画布由 n 2 n^{2} n2 个像素组成，其中第 x x x 列、第 y y y 行的像素记为 ( x , y ) (x,y) (x,y)。

每个像素都有一个整数亮度 V ( x , y ) V(x,y) V(x,y)。最开始，所有像素的亮度均为 0 0 0。

Rimi 会进行恰好 n n n 次上色操作。每次上色操作会给出五个整数 x 1 , x 2 , y 1 , y 2 , v x_{1},x_{2},y_{1},y_{2},v x1​,x2​,y1​,y2​,v， 这表示她选中矩形区域 [ x 1 , x 2 ] × [ y 1 , y 2 ] \lbrack x_{1},x_{2}\rbrack \times \lbrack y_{1},y_{2}\rbrack [x1​,x2​]×[y1​,y2​] 中的所有像素，并将它们的亮度提高到至少 v v v。

形式化地，对于所有满足 x 1 ≤ x ≤ x 2 , y 1 ≤ y ≤ y 2 x_{1} \leq x \leq x_{2},y_{1} \leq y \leq y_{2} x1​≤x≤x2​,y1​≤y≤y2​ 的像素 ( x , y ) (x,y) (x,y)，执行 V ( x , y ) ← max ⁡ ( V ( x , y ) , v ) \left. V(x,y)\leftarrow\max(V(x,y),v) \right. V(x,y)←max(V(x,y),v)。

由于边界主义的作画规则，每个色块必须从画布的左边界或右边界延伸出来。因此，对于每一次上色操作，都保证 x 1 = 1 x_{1} = 1 x1​=1 或者 x 2 = n x_{2} = n x2​=n。

完成所有上色操作后，Rimi 想要检查画面中若干个矩形区域的整体亮度。

她会提出 m m m 次询问。每次询问给出四个整数 x 1 , x 2 , y 1 , y 2 x_{1},x_{2},y_{1},y_{2} x1​,x2​,y1​,y2​，你需要回答矩形区域中所有像素最终亮度之和，即 ∑ x = x 1 x 2 ∑ y = y 1 y 2 V ( x , y ) \sum_{x = x_{1}}^{x_{2}}\sum_{y = y_{1}}^{y_{2}}V(x,y) ∑x=x1​x2​​∑y=y1​y2​​V(x,y)。

Input

第一行一个整数 T ( 1 ≤ T ≤ 50 ) T(1 \leq T \leq 50) T(1≤T≤50)，表示数据的组数。对于每组数据：

第一行两个整数 n , m ( 1 ≤ n , m ≤ 2 × 10 5 ) n,m(1 \leq n,m \leq 2 \times 10^{5}) n,m(1≤n,m≤2×105)；

接下来 n n n 行每行五个整数 x 1 , x 2 , y 1 , y 2 , v x_{1},x_{2},y_{1},y_{2},v x1​,x2​,y1​,y2​,v，依次表示每次上色操作；

接下来 m m m 行每行四个整数 x 1 , x 2 , y 1 , y 2 x_{1},x_{2},y_{1},y_{2} x1​,x2​,y1​,y2​，依次表示每次查询操作；

每个修改或查询操作均满足 1 ≤ x 1 ≤ x 2 ≤ n , 1 ≤ y 1 ≤ y 2 ≤ n 1 \leq x_{1} \leq x_{2} \leq n,1 \leq y_{1} \leq y_{2} \leq n 1≤x1​≤x2​≤n,1≤y1​≤y2​≤n。

每个修改操作均满足 1 ≤ v ≤ n 1 \leq v \leq n 1≤v≤n，且保证 x 1 = 1 x_{1} = 1 x1​=1 或者 x 2 = n x_{2} = n x2​=n。

对于所有数据，保证 n n n 的总和和 m m m 的总和均不超过 10 6 10^{6} 106。
