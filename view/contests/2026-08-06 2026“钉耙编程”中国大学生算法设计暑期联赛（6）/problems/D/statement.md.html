D. Three Colors

Problem Description

小 C 在便利店购物，店内共有三种类型的物品，分别记为 A , B , C \texttt{A},\texttt{B},\texttt{C} A,B,C。商店中的商品按顺序摆放，形成一个长度为 n n n 的字符串 s s s，其中 s i ∈ A , B , C s_{i} \in {\texttt{A},\texttt{B},\texttt{C}} si​∈A,B,C 表示第 i i i 件商品的类型。

小 C 想从指定的一段商品中挑选一段 连续 的商品送给小 X。

现在有 q q q 次询问，每次给出一个区间 [ l , r ] \lbrack l,r\rbrack [l,r]。你需要在区间 [ l , r ] \lbrack l,r\rbrack [l,r] 内选择一个连续子区间 [ l ′ , r ′ ] \lbrack l^{\prime},r^{\prime}\rbrack [l′,r′]（满足 l ≤ l ′ ≤ r ′ ≤ r l \leq l^{\prime} \leq r^{\prime} \leq r l≤l′≤r′≤r）。

设该子区间内三种商品出现次数分别为 c n t A , c n t B , c n t C {cnt}_{\texttt{A}},{cnt}_{\texttt{B}},{cnt}_{\texttt{C}} cntA​,cntB​,cntC​，其中未出现的商品类型出现次数视为 0 0 0。要求三种商品的出现次数两两不同，即 c n t A ≠ c n t B {cnt}_{\texttt{A}} \neq {cnt}_{\texttt{B}} cntA​=cntB​ 且 c n t A ≠ c n t C {cnt}_{\texttt{A}} \neq {cnt}_{\texttt{C}} cntA​=cntC​ 且 c n t B ≠ c n t C {cnt}_{\texttt{B}} \neq {cnt}_{\texttt{C}} cntB​=cntC​。

对于每次询问，输出一个满足条件且长度最大的子区间 [ l ′ , r ′ ] \lbrack l^{\prime},r^{\prime}\rbrack [l′,r′]。若存在多个长度最大的答案，输出任意一个即可；若不存在满足条件的子区间，则输出 0 0。

  • y = ( ( y ′ ⊕ last_ans ) − 1 ) ⁡ n + 1 y = ((y^{\prime} \oplus \text{last\_ans}) - 1)\operatorname{}n + 1 y=((y′⊕last_ans)−1)n+1。

对于每次询问，输出两个用空格分隔的整数 l ′ l^{\prime} l′ 和 r ′ r^{\prime} r′，表示你选择的满足条件且长度最大的连续子区间的左右端点。若有多个长度相同的合法答案，输出任意一个；若无解，请输出 0 0。
